## CN2 GIA、AS9929、AS4837、CMIN2 差在哪

**CN2 GIA 是中国电信自营的下一代承载网里的最高等级产品**，回程全程走 CN2 节点，不挤公共互连，电信用户延迟低、晚高峰丢包少，对联通和移动的优化相对弱。需要分清的是 CN2 GT、CN2 GIA，以及“只在部分路段经过 CN2”的产品，三者在套餐标题里都敢写 CN2，实际路径完全不同，只能看具体套餐和实测路由。

**AS9929 是联通的精品骨干网**，地位大致相当于联通版的 CN2 GIA，联通用户体感优秀。**AS4837 是联通的常规骨干**，比 9929 低一档，但明显好于纯公共国际线路，特点是带宽大、价格便宜。这两条线常被拿来排座次，实际情况没那么绝对：AS9929 不一定在所有城市都比 AS4837 快，AS4837 也不等于晚高峰一定拥塞，关键看机房的互联容量和当地出口。联通用户预算有限时，先测 AS4837 再决定要不要加钱。

**CMIN2 是移动国际的精品方向**，优先级高于普通 CMI。CMIN2 是一个线路方向，不是所有移动用户的固定答案，香港、日本、新加坡这些近距离节点上的优质 CMI 直连，实际体验可能和远距离的 CMIN2 打平甚至更好。

## 三网优化不等于三网同线路，AkkoCloud 的做法又是另一种

市面上讲三网优化，通常指分网选路：电信走 CN2 GIA 或其他电信优化路径，联通走 AS9929、AS4837 或联通直连，移动走 CMIN2、CMI 或移动直连，境外侧用 BGP 给不同运营商挑不同出口。目标是避免其中一家严重绕路或者打不开，而不是让三家的延迟数字一模一样。有些商家把“同时接入三条精品线路”当成卖点强调，那是宣传口径；从技术上看，三网都经过同一个节点并不天然更好，关键看每个方向是否稳定。

AkkoCloud 欧洲节点的设计逻辑跟上面这套不一样：**三网回程统一强制走 CN2 GIA**，去程电信、联通走 CN2 GIA，移动走直连。这相当于把三条回程路径都放到电信的精品网上，对电信用户最友好，联通和移动的回程也优于公共互联，但延迟不会跟联通 9929、移动 CMIN2 的原生路径完全一致。移动用户如果对延迟特别敏感，去程直连这一段值得单独测一次，不要只看回程路由就觉得万无一失。

对大多数自用场景来说，这种设计的实际意义是：你不需要为了照顾家里另一台移动手机而换产品，回程那一段已经统一处理了。

## 按使用场景挑配置，不必按价格挑

**主要供自己使用**（SSH、面板、远程桌面、文件同步）：优先优化自己家那条宽带就够了。电信用户看 CN2 GIA，联通用户比较 9929 和 4837，移动用户看 CMIN2 或 CMI，不必为了兼顾三网多付钱。1核1G 的入门配置跑这些绰绰有余。

**网站面向全国访客**：三网可用性排在第一位，其次是晚高峰丢包、路由稳定性、实际吞吐，最低 Ping 反而最不重要。单台 VPS 很难在所有地区都完美，访客量上来之后该考虑 CDN 或多源站，而不是继续找一条不存在的全能线路。

**办公室有多条宽带**：主线是电信、手机热点是联通这种情况很常见。选两条网络都能稳定访问的产品，必要时做故障切换，不要把可用性全压在一条回程上。

**客户集中在特定地区**：华南、华东、华北的出口和互联情况可能不同，商家给的广州测试结果不能直接代表北京或成都。

不同用途该盯的指标也不一样：

| 使用场景 | 第一指标 |
| --- | --- |
| SSH 管理 | 抖动 |
| 远程桌面 | 丢包 |
| 网站访问 | 三网可用性 |
| 接口服务 | 超时率 |
| 文件下载 | 吞吐 |
| 视频业务 | 带宽与流量额度 |

远程桌面不一定需要最低 Ping，但非常怕延迟突然拉高；网站不一定需要极高带宽，但不能让某家运营商完全打不开。按这个表对号入座，比笼统地问“哪个最快”有用。

欧洲这一行值得多说两句。物理距离摆在那里，普通国际线路从法兰克福回国，晚高峰丢包和绕路基本没法避免；走 CN2 GIA 之后延迟能压到 180ms 量级，这个数字比洛杉矶的 130–160ms 高，但比同距离的普通线路稳定得多。如果你的业务需要欧洲 IP、面向欧洲受众，或者单纯需要一台不在美西的机器做备份和分流，法兰克福和伦敦是目前较少见的选项。

## 下单前的六步测试，以及测完怎么判断

1. 记下自己所在城市和主要运营商。
2. 向厂商索取目标套餐的测试 IP。
3. 白天做一轮 Ping、MTR，去程回程都看。
4. 北京时间晚高峰（20:00–23:00）再测一次。
5. 有全国访客的话，补测另外两家运营商。
6. 先月付或试用，稳定之后再考虑长期付款。

两个容易忽略的点：不要只测商家首页的 IP，官网、测试 IP 和实际购买节点可能不在同一张网络上；单次 Ping 说明不了任何问题，晚高峰那一轮才是决定性的。

| 测试结果 | 该怎么做 |
| --- | --- |
| 电信明显最好 | 选电信向产品 |
| 联通明显最好 | 9929 或 4837 |

## 六个常见误区

**只认“CN2”两个字。** CN2 GT、CN2 GIA 和只在部分路段经过 CN2 的产品不是一回事，59.43 出现在路由里也不代表整条路径、整个计费周期、所有城市都稳定。

**联通用户默认 CN2 GIA 最好。** CN2 GIA 主要面向电信方向，联通用户该同时比较 AS9929、AS4837 和自己的实测结果，别照着电信用户的评价下单。

**移动用户只看机房距离。** 香港很近，但低价共享线路晚高峰照样拥塞；洛杉矶更远，CMIN2 或优质 CMI 反而更稳。物理距离只是变量之一。

**把三网优化理解成三网同线路。** 合理的三网优化是分网选路，回程统一走一条精品线（比如 AkkoCloud 欧洲节点全部回程 CN2 GIA）是另一种取舍，两者都成立，但适用人群不同。

**用一次 Ping 决定年付。** 单次测试既代表不了晚高峰，也看不出回程和吞吐。而年付套餐大多不支持退款，这一步错了只能认。

**把端口带宽当成回国保证带宽。** 1Gbps 是网卡接入规格，跨境链路、共享上游和单线程 TCP 都会把实际速度拉下来。

另外补一条表里看不出来的：流量算双向还是单向，各家差别很大。同样是“1T 流量”，双向计费的机器实际能跑的出站流量只有单向计费的一半左右，买之前把这一项算进额度里。
